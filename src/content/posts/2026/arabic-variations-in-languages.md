阿拉伯语使用的阿拉伯字母有这些：ا ب ت ث ج ح خ د ذ ر ز س ش ص ض ط ظ ع غ ف ق ك ل م ن ه و ي 

同时还有两个变体字母：ة ى

## 印度-伊朗语族
### 波斯语
波斯语是伊朗使用的语言，继承了大部分阿拉伯字母，但是使用ک代替了ك，使用了ی代替了ي，使用的阿拉伯字母相对于阿拉伯语的增加了四个：پ چ ژ گ，分别代表发音/g/，

在早期的波斯语中，ك仍然使用，ڤ被用于表示发音/β/，在这个发音消失后这个字母被废弃。

### 普什图语
普什图语是阿富汗的官方语言。和波斯语一样，普什图语使用了ک代替了ك，也沿用了很多波斯语的字母，同时自制的大量特殊字母（以东南方言为例）：

| 字母 | 转写 | 发音 |
| ---- | ---- | ---- |
| ټ | ṭ | /ʈ/ |
| ځ | ź,g,dz | /d͡z/ |
| څ | ś,c,ts | /t͡s/ |
| ډ | ḍ | /ɖ/ |
| ړ | ṛ | /ɽ/ |
| ږ | z̄ | /ʒ/ |
| ښ | s̄ | /ʃ/ |
| ګ | g | /g/ |
| ڼ | ṇ | /ɳ/ |
| ں | ˜ | /˜/ |
| ې | e | /e/ |
| ۍ | əy | /əj/ |

有趣的是ں这个字母的中间式和后连式上面会多出一点。同时普什图语还自己发明了一个变音符号： ◌ٙ

### 库尔德语
库尔德语的阿拉伯字母版本主要用于中库尔德语。字母表同样沿用了许多波斯语字母，同时在ه的基础上造出了ھ和ە用来表示/h/和/ɛ/音。除此之外还增加了以下字母：

| 阿拉伯 | 发音 |
| ------ | ---- |
| ڕ | /r/ |
| ڤ | /v/ |
| ڵ | /ɫ/ |
| ۆ | /oː/ |
| ێ | /eː/ |

### 乌尔都语
乌尔都语是巴基斯坦的官方语言。这个语言使用的字母表基于波斯语的，并且通常使用波斯体书写。

乌尔都语使用的ه非常特殊，包括ہ ۃ ۂ这三个字符
ہہہہ
